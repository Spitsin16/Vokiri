# Vokiri — передача разработчикам

Финальная выбранная версия на 9 сентября 2026.

## Что использовать
- avatars/: готовая аватарка в PNG, 1024 и 512 px, светлый и тёмный варианты. Квадратные варианты подходят для автоматического круглого обрезания в профиле. rounded — для презентаций, с прозрачными углами.
- logos/wordmark.svg: основной логотип. Первую v заменяют две кавычки, далее okiri. Это единый готовый знак: не добавлять ещё одну v. wordmark-inverse.svg — для тёмного фона. PNG имеют прозрачный фон.
- logos/mark.svg: только кавычки. Используется в аватарке, иконке и маленьких форматах.
- icons/: PNG 180, 192, 512, 1024 px и SVG. Для iPhone — 180 px; для web manifest — 192 и 512. Иконки имеют квадратный фон, скругление выполняет платформа.
- colors/: утверждённая молочно-зелёная палитра в JSON и CSS. colors.json отдельно фиксирует фактические переменные текущего интерфейса, чтобы не потерять небольшие различия оттенков.
- fonts/: настоящие variable TTF Manrope, DM Sans и DM Sans Italic, CSS для локального подключения, лицензии OFL. Manrope — заголовки, DM Sans — основной интерфейс и тексты. Manrope включает кириллицу. DM Sans — латиница; для русского текста используйте Manrope как fallback: font-family: "DM Sans", "Manrope", sans-serif.
- reference-ui/: рабочий статический фронтенд для сверки. Запускать HTTP-сервер из корня всего комплекта, открывать /reference-ui/. Это демо: данные локальные, тексты подготовленные, настоящей AI-генерации пока нет.

## Шрифт логотипа
Основа — Avenir Next Bold, второй выбранный образец. В SVG буквы переведены в кривые: шрифт для показа логотипа не нужен. Коммерческий исходный файл Avenir Next не включён. Если потребуется перенабирать название или использовать Avenir как интерфейсный шрифт, разработчику нужна соответствующая лицензия. Не заменять уже готовые кривые другим шрифтом.

## Параметры
Основной текст 16–18 px; заголовки Manrope 500; мелкие рабочие подписи 14 px. Для wordmark в шапке: desktop 132 px по ширине, mobile 105 px, высота auto. Не менять пропорции. Подпись PERSONAL ENGLISH добавляется отдельно и не входит в знак.

Фирменные цвета: Ink #262C20, Paper #F3F3ED, Signal #D6F477, Olive #637239, Quiet #E2E7D9. Оранжевый вариант отклонён. Белые и инверсные знаки не ставить на светлый фон.

Анимация: мягкая однократная подсветка английского слова, 850 ms; отключение через prefers-reduced-motion. Нажатие открывает значение. Нет PNG-персонажа или отдельной анимационной картинки; не имитировать такой ассет.

Сохранить ключ localStorage english-hub-v1 при переносе текущего фронтенда. Работа на другом домене не переносит браузерные данные автоматически. Не считать первое успешное повторение словом, выученным навсегда.
